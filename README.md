# MoveBandhu (Kolhapur • Sangli • Satara) — Pure JavaScript MERN Stack

Welcome to **MoveBandhu**, the Western Maharashtra home shifting and logistics platform covering **Kolhapur (MH 09)**, **Sangli (MH 10)**, and **Satara (MH 11)**!

## Pure MERN Stack (Zero TypeScript / TSX)
This archive contains 100% pure standard JavaScript code:
- **M - MongoDB:** Mongoose ORM configured with automatic file-backed JSON store in `/data/movemate_store.json` (starts immediately with zero configuration; connect to MongoDB Atlas by providing `MONGODB_URI` in `.env`).
- **E - Express.js:** Modular backend in standard JavaScript (`.js`) with REST routes for Auth, Bookings, Pricing, Inquiries, Partners, and Admin.
- **R - React 19:** React components in standard JSX (`.jsx`) with Tailwind CSS and Lucide icons.
- **N - Node.js:** Full-stack runtime in standard modern JavaScript (ES Modules, `"type": "module"`).

> **Zero TypeScript setup required:** All files are pure `.js` and `.jsx`. No `tsconfig.json`, no `tsx` binary, and no type declarations needed.

## Quickstart (2 Steps)

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Full-Stack Dev Server:**
   ```bash
   npm run dev
   ```
   Open your browser at: **http://localhost:3000**

3. **Production Build & Start:**
   ```bash
   npm run build
   npm start
   ```
